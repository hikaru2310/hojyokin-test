# 賃上げ原資シミュレーター

商談中に使う見積もりツールです。賃上げで増える年間固定費に対して、助成金・補助金・税制・社会保険料の適正化・AIワークフローでどれだけ補填できるかを試算します。

## 使い方

`index.html` をブラウザで開くだけで動きます（ビルド不要・外部通信はフォントのみ）。

1. 左の「企業情報」に業種・事業形態（法人/個人事業主）・資本金・年度・都道府県・従業員数・有期/パート人数・平均年収・事業場内最低賃金・法人税額を入力
   - 地域別最低賃金は都道府県と年度から自動で入ります（手入力で上書き可）
   - 中小企業の判定は「資本金または従業員数」のどちらかが業種の基準以下かで行います
2. 「賃上げ計画」に年間固定費アップ額（例：100万円）を入力。目安の3倍を超えたかをグラフと表示で確認できます
   - 前年度の給与総額（任意）を入れると、賃上げ促進税制の増加率をその額で計算します。空欄なら「従業員数×平均年収」
3. 右側で施策ごとにチェックのオン/オフ、「条件を調整」で投資額や人数を変更
4. 「提案サマリーをコピー」でメール・チャットに貼れるテキストを取得

入力欄には「必須」「任意」を表示しています。必須項目だけで提案候補とインパクトが出て、任意項目を入れると判定できる制度が増えます。入力中の内容はブラウザ（localStorage）に残ります。「初期値に戻す」でリセットできます。

## 画面構成（タブ）

| タブ | 内容 |
| --- | --- |
| 提案・インパクト | 施策の候補と概算額、目安3倍との比較 |
| 実行ロードマップ | チェックした施策の「誰が・いつ・何を」を月単位で表示。お客様／当社／税理士／社労士で色分けし、担当を選ぶとその作業だけを強調。◆は制度側の期限（公募締切・交付決定・入金など）。共通書類（履歴事項全部証明書・納税証明書など）をまとめて使える取得月も表示 |
| 専門家連携レポート | 顧問税理士・社労士に渡す依頼事項（圧縮記帳、賃上げ促進税制の適用判定、助成金の申請など）を制度ごとに自動作成。コピー・印刷に対応 |
| 保存データ | 「提案を保存」した顧客情報・ヒアリング内容・試算結果の一覧。読み込み・削除、スプレッドシート貼り付け用のコピー、CSVダウンロード |

ロードマップの月は「着手予定月」を起点にした目安です。各施策の工程は `index.html` 内の `FLOW`、共通書類は `DOCS` で定義しています。

## スプレッドシートへの保存

- **手動**：「保存データ」タブの「表形式でコピー」をスプレッドシートに貼り付けるか、CSVを取り込みます。1提案が1行、施策ごとの金額は列に分かれます。
- **自動**：`gas/Code.gs` を保存先スプレッドシートの Apps Script に貼り付けてウェブアプリとしてデプロイし、URLを「保存データ」タブに設定すると、「提案を保存」のたびに「提案データ」シートへ1行追加されます。公開版（claude.ai のページ）からは外部送信できないため、`index.html` を直接開いて使います。

## 試算の考え方

| 指標 | 計算 |
| --- | --- |
| 初年度インパクト | 一時的な効果（助成金・補助金・税額控除）＋毎年の効果（社保適正化・AI） |
| 倍率 | 初年度インパクト ÷ 年間固定費アップ |
| 3年累計の倍率 | （一時的な効果＋毎年の効果×3）÷（年間固定費アップ×3） |

表示オプション

- **会社負担の社会保険料を含めて比較**：固定費アップを「賃上げ額×(1＋会社負担率)」で計算
- **採択見込みを反映した期待値で表示**：補助金・助成金を「金額×採択見込み%」で計上

## 収録している施策

| 区分 | 施策 | 主な計算根拠 |
| --- | --- | --- |
| 助成金 | 業務改善助成金 | 引上げ額コース×人数の上限、助成率3/4（事業場内最低賃金1,000円未満は4/5） |
| 助成金 | キャリアアップ助成金（正社員化） | 1人80万円（重点）/40万円、制度新設加算20万円 |
| 助成金 | キャリアアップ助成金（賃金規定等改定） | 引上げ率3%〜6%以上で1人4万〜7万円 |
| 助成金 | 人材開発支援助成金（リスキリング） | 経費75%＋賃金助成1,000円/時 |
| 補助金 | デジタル化・AI導入補助金（旧IT導入） | 1/2（最低賃金近傍は2/3）、上限450万円 |
| 補助金 | 小規模事業者持続化補助金 | 2/3、上限50万円（賃金引上げ特例で200万円） |
| 補助金 | 省力化投資補助金（カタログ型・一般型） | 従業員数別の上限、1/2（小規模2/3） |
| 補助金 | ものづくり補助金 | 従業員数別の上限、大幅賃上げ特例 |
| 補助金 | 中小企業新事業進出補助金 | 1/2、下限750万円 |
| 税制 | 賃上げ促進税制（中小企業向け） | 増加率1.5%で15%、2.5%で30%、教育訓練+10%、くるみん等+5%、上限は法人税額の20% |
| 社会保険 | 選択制確定拠出年金 | 拠出額×会社負担の社保率−運営費 |
| AI | AIワークフロー導入 | 削減時間×時間単価（社保込み）−ツール費 |

都道府県と年度から地域別最低賃金を自動で設定し、事業場内最低賃金との差額（50円以内か）で業務改善助成金の対象判定や、デジタル化・AI導入補助金の補助率に反映します。地域別最低賃金は `PREFS` に令和7年度の全都道府県額と、確認できた令和8年度の答申額を収録しています（未登録の県は令和7年度額で代用し、画面に警告を出します）。

業種は、中小企業・小規模事業者の判定、雇用保険率・労災保険率、AIで削減しやすい業務の例に反映されます。年度は社会保険料率（2026年度の子ども・子育て支援金を含む）に反映されます。

## 注意

金額・料率は2025年度時点の公表内容をもとにした目安です。2026年度は制度の改正・統合・名称変更があり得るため、提案前に最新の公募要領・支給要領で確認してください。マスタは `index.html` 内の `INDUSTRIES` / `RATES` / `ITEMS` にまとまっているので、要領の改定時はここを更新します。
